# Plan de Pruebas

| Caso | Descripción | Resultado esperado |
|------|--------------|--------------------|
| 1 | Cliente se conecta al servidor | Conexión exitosa |
| 2 | Enviar mensaje a otro cliente | Cliente destino recibe mensaje |
| 3 | Enviar mensaje broadcast | Todos los clientes reciben |
| 4 | Cliente desconectado | El servidor lo elimina de la lista |
| 5 | Solicitud de lista | Devuelve lista de clientes conectados |
| 6 | Notificación en Windows | Aparece toast con mensaje recibido |
